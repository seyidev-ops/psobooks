# Pastor Sarah Omakwu Books

The official book website for Pastor Sarah Omakwu's teaching series:

1. **The Big Is in the Small** — Faithfulness, Wise Stewardship, and an Inheritance for Your Children's Children (2011)
2. **Living Ready** — Lessons from Abraham for Those Who Wait for the City (2004)
3. **Walking on the Straight and Narrow** — Choosing the Narrow Gate in the Last Days (2018)
4. **Knowing Jesus For Yourself** — Laying a Biblical Foundation (2026)

A single static page (`index.html`) with no build step. Deploy with GitHub Pages, Netlify or any static host.

## Files
- `index.html` — the site, with SEO meta, Open Graph/Twitter cards and JSON-LD (Person, BookSeries, FAQPage)
- `pastor-sarah-omakwu.webp` — author portrait
- `og-image.jpg` — 1200×630 social share image
- `favicon.webp`, `robots.txt`, `sitemap.xml`
